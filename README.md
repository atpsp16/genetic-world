# GENETIC WORLD: โรงงานผลิตสิ่งมีชีวิต

เกมการเรียนรู้เรื่องการถ่ายทอดลักษณะทางพันธุกรรม ชั้น ม.3 (เว็บเกม ไม่ต้องติดตั้ง)
เล่นได้บน iPad โทรศัพท์ (แนวตั้ง/แนวนอน) และคอมพิวเตอร์

เล่นออนไลน์: https://atpsp16.github.io/genetic-world/

## เปิดเล่นในคอมพิวเตอร์
ดับเบิลคลิก `index.html` ได้เลย (Chrome / Edge)

## แก้ไขเนื้อหา
ทุกอย่างที่แก้บ่อยอยู่ในไฟล์ `js/data.js`
- ชื่อผู้พัฒนา / โรงเรียน → `GW.CONFIG` (เว้นว่างไว้ = ไม่แสดง)
- บทเรียน พ่อแม่พันธุ์ ประวัติ → `GW.LEVELS`
- ใบสั่งด่านบอส → `GW.BOSS`
- แบบทดสอบก่อน-หลังเรียน → `GW.QUIZ`
- ข้อมูลหน้า "สำหรับครู" (ตัวชี้วัด, 5E, ทฤษฎี) → `GW.TEACHER`

## นำขึ้นเว็บเพื่อเล่นบน iPad
อัปโหลดทั้งโฟลเดอร์ขึ้นเว็บโฮสต์ฟรีที่เป็น https เช่น GitHub Pages หรือ Netlify
แล้วเปิดลิงก์ใน Safari → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
เปิดจากไอคอนนั้น 1 ครั้งตอนมีเน็ต หลังจากนั้นเล่นแบบไม่มีอินเทอร์เน็ตได้

**ถ้าแก้ไฟล์แล้วอัปโหลดใหม่:** เพิ่มเลขเวอร์ชัน `genetic-world-v2` ในไฟล์ `sw.js` (v3, v4 …)
ไม่อย่างนั้นเครื่องที่เคยเปิดเกมไว้จะยังใช้ไฟล์เก่า

## เครื่องมือครู (ซ่อนอยู่) และโหมดสาธิต
หน้าแรก → "สำหรับครู" → **แตะไอคอน DNA บนหัวหน้า 5 ครั้งติดกัน** ส่วน "เครื่องมือครู" จะปรากฏ
- โหมดสาธิต: ปลดล็อกทุกบท กดข้ามไปสถานีไหนก็ได้ มีปุ่ม ✨ เติมคำตอบ และทางลัดไปช่วงไฮไลต์
- รหัสเซฟ และปุ่มเริ่มใหม่ทั้งหมด
แตะ 5 ครั้งอีกรอบเพื่อซ่อน

## กระดานคะแนนออนไลน์ (Firebase)
ผู้เล่นใส่ชื่อเล่นและรหัสห้อง คนที่ใช้รหัสห้องเดียวกันจะเห็นอันดับเดียวกันทุกเครื่อง (หน้า 🏆)
คะแนนแต่ละบท = 100 − 10 × จำนวนครั้งที่ตอบผิด (ต่ำสุด 20) นับครั้งที่ดีที่สุด รวมเต็ม 400

ตั้งค่าครั้งเดียว:
1. เข้า https://console.firebase.google.com ด้วยบัญชี Google → สร้างโปรเจกต์ (ปิด Google Analytics ได้)
2. เมนู Build → Realtime Database → Create Database → เลือก Singapore → Start in locked mode
3. แท็บ Rules → ลบของเดิม วางเนื้อหาไฟล์ `firebase-rules.json` → Publish
4. คัดลอกลิงก์ฐานข้อมูล (ลงท้าย `firebasedatabase.app`) ใส่ใน `js/data.js` ที่ `GW.ONLINE.databaseURL`

ถ้าไม่ได้ตั้งค่า กระดานจะแสดงเฉพาะผู้เล่นในเครื่องนั้น
ลบคะแนนเก่า: Firebase Console → Realtime Database → Data หรือใช้รหัสห้องใหม่
